# Tiny Chatbot UltraChat Subword v3 Assistant-Loss Run

Date recorded: 2026-05-17

## Purpose

This run tested the first assistant-only supervised chat objective. It used the
same broad `8x512` UltraChat setup as `v2_fixed`, but changed training from
all-token next-token LM loss to assistant-only loss.

The goal was to reduce fake user turns and improve direct assistant behavior.

## Training Recipe

- Dataset: `tmp/tiny_chatbot_ultrachat_corpus_v1`
- Tokenizer: reused `v1` `KeemenaSubwords.jl` GPT-2 byte-BPE tokenizer
- Vocab size: `8192`
- Context length: `128`
- Model:
  - layers: `8`
  - heads: `8`
  - embedding size: `512`
  - FFN hidden size: `2048`
- Backend: Flux
- Device: GPU, RTX 5000 Ada by UUID
- Loss mode: `assistant_only`
- Optimizer: `Flux.Adam(0.0003)`
- Batch size: `16`
- Epochs: `2`
- Training text limit: `100000`
- Validation text limit: `1000`
- Test text limit: `1000`

Training command used:

```bash
CUDA_VISIBLE_DEVICES=GPU-10d1f16f-9e79-08bb-b2ba-3353c04422cf julia --project=tools/subword_real_text tools/run_tiny_chatbot_ultrachat_subword_v1.jl --dataset-dir tmp/tiny_chatbot_ultrachat_corpus_v1 --output-dir tmp/tiny_chatbot_ultrachat_subword_candidate_run_v3_assistant_loss --device gpu --loss-mode assistant_only --context-length 128 --num-layers 8 --num-heads 8 --embedding-size 512 --ffn-hidden-size 2048 --batch-size 16 --epochs 2 --learning-rate 0.0003 --reuse-tokenizer-bundle-dir tmp/tiny_chatbot_ultrachat_subword_candidate_run_v1/tokenizer_bundle --train-text-limit 100000 --validation-text-limit 1000 --test-text-limit 1000 --checkpoint-every-steps 5000 --max-step-checkpoints 2 --max-epoch-checkpoints 2
```

Important comparison caveat:

- These losses are assistant-only losses and are not directly comparable to the

## Qualitative Result

The model still failed the chatbot-quality goal.

Observed behavior:

- greedy decoding still repeats list/template patterns
- sampling can produce nonsensical fragments
- wrong-task drift remains common
- the model can answer in fluent-looking text but often ignores the actual user
  request

Conclusion:

- The assistant-only objective is a better training setup, but it was not enough
  to overcome corpus/style problems.
- More epochs on this same setup are unlikely to solve the issue.
- The next useful direction is a cleaner short-answer SFT corpus and
  example-based batching, not another repeat of the same broad UltraChat stream.
